# Overdue Comments

I have refactored my devcontainer code so the course runs ok. One issue I found was `sudo apt-get update` exited with error code 100 which stopped the containers building.  The trick i found was to replace this with `sudo apt-get update || true` which meant I could ignore the exit code. 

Another problem I had was pushing an image using `docker tag <image id> lovellbrian/cpu` and then `docker push` (I remembered the instuctions wrongly).  This should have been `docker commit <container id> lovellbrian/cpu` followed by `docker push`.  This reulted in a much larger image being pushed which contained all the local files I had created.
